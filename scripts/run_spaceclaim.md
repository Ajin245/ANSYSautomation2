# SpaceClaim: запуск скриптов руками (ANSYS 21R1)

Консольный запуск SpaceClaim в 21R1 **не подтверждён**, поэтому оба скрипта запускаются из GUI.
Это две операции на проект; выполняются до batch-прогона Mechanical.

## Порядок

1. Открыть в SpaceClaim 21R1 модель конструкции (`.scdoc`), для которой идёт расчёт.
2. `File` → `Script` → `Run...` (в некоторых сборках — `File` → `Run Script...`).
3. Выбрать `src/SpaceClaim/prepare_geometry.py`, запустить, дождаться завершения.
4. Не закрывая документ, снова `File` → `Script` → `Run...` и выбрать
   `src/SpaceClaim/create_named_selections.py`.
5. Сохранить документ (`.scdoc`) и передать его в проект Workbench.

## Что должно появиться в дереве

После `prepare_geometry.py`:

- поверхностные тела очищены/объединены по правилам скрипта;
- трубы повёрнуты нужной осью, сборка перенесена в начало координат;
- вспомогательные плоскости, которые создаёт скрипт, видны в дереве.

После `create_named_selections.py`:

- группы/выборки `gu_fixed`, `gu_force`, `gu_remote_disp`;
- выборки по префиксам тел (болты — `gu_bolt*_f`, остальные — по правилам
  `create_named_selections.py`);
- в каждой выборке непустой список тел.

## Если скрипт упал

1. Прочитать сообщение в окне Script / Output SpaceClaim — там имя шага и текст исключения.
2. Проверить, что открыт нужный документ и что ID конструкции определяется корректно:
   скрипты берут его из `STRUCTURE_ID` или из имени документа, иначе бросают `StructureIdError`.
3. Проверить, что первый скрипт действительно завершился: второй рассчитывает на подготовленную
   геометрию и созданные плоскости.
4. Зафиксировать текст ошибки и шаг в протоколе прогона; не «обходить» ошибку ручной правкой
   геометрии без записи в протокол.
5. Если ошибка в самом скрипте — это отдельная карточка Программисту, а не правка «на месте».

## Чего здесь нет

Автоматического запуска SpaceClaim из `run_ansys.bat`. В 21R1 такой режим не подтверждён;
обещать «ноль кликов» для геометрии нельзя.
